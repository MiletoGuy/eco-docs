# Requisitos do sistema

| Recurso | Smartphone | Tablet |
|----------|-------------|---------|
| **Processador** | 4 x 1.2 Ghz Core | 4 x 2.3 Ghz + 4 x 1.8 Ghz Core |
| **Memória RAM** | 1.5 GB | — |
| **Armazenamento** | 40 MB para instalação | — |
| **Tela** | 5” (720x1280 px / 294 ppi) | 8.7” (800x1340 px / 179 ppi) |
| **Câmera** | 5 MP com autofoco | — |
| **Conectividade** | Internet móvel (4G) e/ou Wi-Fi | — |
| **Sistema Operacional** | Android 7 (Nougat) ou superior | — |

> **Importante:** As aplicações funcionam apenas em dispositivos **homologados pela Anatel**.
