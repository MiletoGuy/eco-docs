# Perguntas frequentes

### 1. Se eu não salvar a OS ou checklist, perco os dados?
Não. Eles ficam armazenados no cache até que você salve ou descarte.

### 2. A checklist é compartilhada com outros aparelhos?
Sim, se for salva. Caso contrário, permanece apenas no cache.  
O compartilhamento é restrito por empresa.

### 3. Posso editar uma OS ou o objeto dela pelo EcoOS?
Não. As edições devem ser feitas no **EcoGestão**.

### 4. A checklist é visível no EcoGestão?
Não. Ela é exclusiva do **EcoOS**.

### 5. Onde fica armazenada a assinatura?
As assinaturas ficam na base **PostgreSQL `ecodados`**, na tabela **`TORDAASSINATURA`**.
